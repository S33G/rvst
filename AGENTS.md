# Working on RVST

Use clear, concise communication. Ask when requirements are uncertain.
Keep plugins in independent repositories; keep audio callbacks allocation-free.
Use ordinary Cargo workflows and distinguish build/validator evidence from DAW qualification.

Load only the skill matching the task:
[new plugin](skills/rvst-new/SKILL.md),
[DSP/UI/SDK changes](skills/rvst-develop/SKILL.md), or
[diagnostics and qualification](skills/rvst-debug/SKILL.md).
Start there; follow references on demand instead of reading all docs.
